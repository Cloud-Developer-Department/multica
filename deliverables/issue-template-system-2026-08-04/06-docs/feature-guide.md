# Issue 模板系统 — 功能说明（用户视角）

**特性**: Issue 模板系统（CLO-159）
**版本**: 0.5.0（规划）
**日期**: 2026-08-04
**角色**: Documentation（杜兰特）
**Issue**: CLO-163 【文档】Issue 模板系统文档更新

---

## 一、这是什么

Issue 模板是一组「Issue 字段预设值」。它把创建 Issue 时经常重复填写的字段（标题、描述、状态、优先级、负责人、项目、阶段、标签）提前存好，之后创建 Issue 时选一个模板，表单自动填好，用户只需微调再提交。

模板按 **工作区（workspace）** 隔离，一个工作区的模板不会出现在另一个工作区。

> 与 Agent 模板系统的区别：Agent 模板（`/api/agent-templates`）预设的是 Agent 的指令、技能、模型；Issue 模板预设的是 **Issue 表单字段**。两者是不同概念。

---

## 二、预置模板

每个**新建**的工作区会自动获得 4 个预置模板，开箱即用：

| 名称 | 分类 | 图标 | 默认优先级 | 标题前缀 | 正文结构 |
|------|------|------|-----------|----------|----------|
| 特性开发 | engineering | sparkles | medium | `【特性】` | 需求描述 / 验收标准 / 影响范围 |
| Bug 修复 | engineering | bug | high | `【Bug】` | 复现步骤 / 期望行为 / 实际行为 / 环境 |
| 需求分析 | planning | lightbulb | medium | `【需求】` | 背景 / 目标 / 方案选项 / 建议下一步 |
| 周报/月报 | planning | list-checks | none | `【周报】` | 本期进展 / 遇到的问题 / 下期计划 |

预置模板的规则：

- **可编辑**：内容可以按团队习惯修改（例如改正文结构、默认优先级）。
- **不可删除**：删除预置模板会被拒绝（HTTP 409），保证每个工作区始终保有基础模板。
- **仅新建工作区播种**：在 `CreateWorkspace` 事务内自动插入，与工作区创建原子提交；已存在的工作区不会自动获得预置模板（详见 FAQ）。

## 三、使用场景

### 3.1 从模板创建 Issue

1. 打开「创建 Issue」对话框（手动创建模式）。
2. 对话框头部、面包屑旁会出现一个「模板」下拉按钮（**仅当当前工作区有模板时显示**）。
3. 选择一个模板，表单会立即预填该模板设置的字段：
   - 标题：拼接模板的 `title_template` 前缀与当前标题
   - 描述：模板的 `body_template`（Markdown）
   - 状态、优先级、负责人、项目、阶段、标签：模板预设的值
4. 调整表单内容后正常提交。

> 行为约定：选择模板会**覆盖**当前表单状态（包括草稿）中模板实际设置的字段；模板没有设置的字段保持不变。这是有意设计——选择模板即表示「我要从模板开始」。

### 3.2 在 Settings 管理模板

入口：工作区 Settings → **Templates** 页签。

支持：

- **列表**：展示所有模板（名称、描述、分类、更新时间），可搜索筛选。
- **新建 / 编辑**：编辑器可配置名称、描述、图标、分类、标题前缀、正文模板、状态、优先级、阶段、负责人（类型+具体对象）、项目、标签。
- **删除**：删除前有确认框；预置模板带 Lock 标记，删除按钮禁用。

### 3.3 谁可以用

- **所有工作区成员**可以读取模板（列表/详情）。
- **owner / admin** 可以写入（创建/更新/删除）。该约束在路由分组层面声明，与 labels 等管理资源的开放模式一致。

## 四、字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 模板名称，必填，≤64 字符，无控制字符 |
| `description` | string | 描述，≤500 字符 |
| `title_template` | string | 标题前缀/预设，应用到新 Issue 标题 |
| `body_template` | string | Markdown 正文预设，≤16000 字符 |
| `status` | enum | `backlog / todo / in_progress / in_review / done / blocked / cancelled` |
| `priority` | enum | `urgent / high / medium / low / none` |
| `assignee_type` | enum | `member / agent / squad` |
| `assignee_id` | UUID | 对应类型的负责人 ID |
| `project_id` | UUID | 预选项目 |
| `stage` | int | 子 Issue 阶段分组，≥1 |
| `label_ids` | string[] | 预选标签 ID（工作区 issue 类型标签），≤50 个 |
| `icon` | string | Lucide 图标名（如 `sparkles`、`bug`），仅展示用 |
| `category` | string | 自由分类（如 `engineering`、`planning`），仅展示用 |
| `is_preset` | bool | 是否预置模板（预置不可删除） |

## 五、边界与已知限制

1. **模板选择器只在「手动创建」面板提供**；Agent 快速创建面板（只有 prompt 输入）未集成。
2. **模板不保证实时创建 Issue**：应用模板是在前端预填表单，最终仍走 `/api/issues` 创建流程；后端未提供 `template_id` 直接创建参数。
3. **跨工作区不可见**：模板按工作区隔离，访问他工作区模板返回 404。
4. **既有工作区无预置模板**：见 FAQ。
