# 页面设计稿：Tab1 生命周期与部门维度（⑥⑦⑧ 条件区块 + PageHeader 部门筛选器）

> 数据接口：L1 `identity/lifecycle`、L2 `identity/departments`；A1–A5 / B1 支持 `department_id` 过滤
> 上游：PRD §4.1 ⑥⑦⑧ / §4.6 / §5.10 / E18–E19；组件规范见 `01-组件规范与Token对齐-阶段8增量.md`
> 定位：在 CLO-236 v1.0 Tab1 设计基础上**追加 ⑥⑦⑧ 区块与 PageHeader 部门筛选器**，不推翻 v1.0 已有 ①–⑤ 模块
> 空值语义：`source_status.ready=false → 引导态/隐藏`、`null → '-'`、`[] → 空态文案`、`0 → 数值零`

## 2. PageHeader 部门筛选器 `DepartmentFilter`（条件显示）

### 2.1 正常态（L2 ready=true）

- 位置：PageHeader 右侧，时间维度 Segmented 之后、时区 Select 之前。
- 视觉：`Select`（`native-select.tsx` 或 `select.tsx`）：
  - 选项：「全部」（value=`all`，默认）+ 部门列表（`L2 items[].name`，value=`department_id`）；
  - 前缀 icon `Building2 size-4 text-muted-foreground`（可选）；label「部门」`text-xs muted`（可选，保持与时间/时区控件一致的紧凑风格）。
- 交互：
  - 切换 → 仅重查 **Tab1（A1–A5）与 Tab2 漏斗（B1）** 接口，请求带 `department_id`；Tab3/Tab4 不重查、不传参（PRD §4.6，避免 400）；
  - 各卡片保留上一部门数据 + 原位 spinner（对齐时间切换模式）；
  - 选中部门后切换时间窗口 → 部门保持，重查带部门参数。

### 2.2 隐藏态（E18）

- L2 `ready=false` → 部门筛选器**不渲染**（页面顶部不出现「部门」控件）；⑥⑦⑧ 显示引导态。

## 3. 模块⑥ 用户生命周期卡 `LifecycleCard`（L1）

### 3.1 正常态

- 容器：`Card`，`CardHeader`：`CardTitle`「用户生命周期」+ `CardAction` `Badge variant="secondary"`「LDAP/手动」。
- 两组指标（`CardContent space-y-4`）：
  - **入职开通率**：
    - `label`：「入职开通率」`text-xs muted`；
    - `value`：`onboarding_rate`×100（`text-2xl font-medium tabular-nums`，`accent="brand"`）；
    - 说明：`text-xs muted`「新入职 {new_hires_total} · 已开通 {onboarded_members}」；
    - `null → '-'`（窗口无新入职样本，口径 §1.4.1）；`onboarding_rate:1.0` → `100%`。
  - **离职权限熔断**：
    - `label`：「离职权限熔断」`text-xs muted`；
    - `value`：`cutoff_events`（`text-2xl font-medium tabular-nums`）；
    - 说明：`text-xs muted`「窗口内离职权限熔断事件数」。
- **最近事件列表**（`divide-y`，Top5，`recent_events`）：
  - 行：事件 `Badge`（onboard=`success`「入职开通」/ offboard=`secondary`「离职」/ cutoff=`warning`「权限熔断」）+ 成员名 `text-sm font-medium` + 时间 `text-xs muted` + 结果 `Badge`（success=`success`「成功」/ failed=`destructive`「失败」/ `null → '-'`）。
- **交互**：点击卡片（或 `CardAction` 放 `Button variant="ghost" size="sm"`「查看明细」）→ `Dialog` 事件明细列表（成员、事件类型、时间、结果）。
- 空值：`onboarding_rate:null` → `-`；`cutoff_events:0` → `0`（非空态）。

### 3.2 引导态（E18）

- `L1.source_status.ready=false` → 卡片内容区 `SourceGuideState`：
  - `EmptyMedia`：`UsersRound`（`size-8`）
  - `EmptyTitle`：「用户身份数据源未接入」
  - `EmptyDescription`：「接入 LDAP/IDP 或配置部门映射后启用。」
  - `Button variant="outline" size="sm"`「前往配置」（身份/部门映射管理）。

### 3.3 空态（有数据但窗口无事件）

- `ready=true` 且 `recent_events:[]` → `Empty`：
  - `EmptyMedia`：`UserRoundPlus`（`size-8`）
  - `EmptyTitle`：「窗口内无入职/离职事件」
  - `EmptyDescription`：「当前时间窗口内没有入职或离职事件，相关指标待事件累积后展示。」

### 3.4 加载态 / 错误态

- 加载：内容区 `Spinner`。
- 错误：`Alert destructive` + 重试。

## 4. 模块⑦ 权限熔断成功率卡 `CutoffSuccessCard`（L1）

### 4.1 正常态

- 容器：`Card`，`CardHeader`：`CardTitle`「权限熔断成功率」+ `CardAction` `Badge variant="secondary"`「LDAP/手动」。
- 单指标（`CardContent space-y-3`）：
  - `label`：「熔断成功率」`text-xs muted`；
  - `value`：`cutoff_success_rate`×100（`text-2xl font-medium tabular-nums`，`accent="success"`）；
  - `Progress`：`value={rate×100}`，indicator `bg-success`；
  - 说明：`text-xs muted`「熔断成功 {cutoff_success_count} / 应熔断 {cutoff_events}」；
  - `null → '-'`（`cutoff_events=0` 无分母，口径 §1.6）。

### 4.2 引导态（E18）

- 同 ⑥：`SourceGuideState`（`ShieldOff` icon + 「用户身份数据源未接入」+ 描述 + 「前往配置」）。

### 4.3 空态 / 加载态 / 错误态

- `ready=true` 且 `cutoff_events=0` → value `-`，说明「窗口内无权限熔断事件」（不整体空态，非错误）。
- 加载：内容区 `Spinner`；错误：`Alert destructive` + 重试。

## 5. 模块⑧ 部门维度切片 `DepartmentSlicer`（L2 + department_id）

### 5.1 正常态（L2 ready=true）

- 容器：`Card`，`CardHeader`：`CardTitle`「部门维度切片」+ `CardDescription`「选择部门后 Tab1/Tab2 按部门成员重新聚合」+ `CardAction` 放 `Select`（与 PageHeader 部门筛选器联动）。
- 部门对比列表（`divide-y`，按 `active_members` 或 `member_count` 降序）：
  - 行 `grid grid-cols-[minmax(0,1.6fr)_auto] gap-3 items-center px-4 py-2`：
    - 列 1：部门名 `text-sm font-medium` + 下注 `text-xs muted`「成员 {member_count} · 活跃 {active_members}」；
    - 列 2：活跃度进度条 `Progress`（`value={active_members/member_count×100}`，`bg-chart-4`，`w-24`）+ 活跃率 `text-xs tabular-nums muted`。
  - 行 `hover:bg-muted`；点击行 → 等同选择该部门（联动 PageHeader 筛选器与 Tab1/Tab2 重查）。
- 空态：`items:[]` → `Empty`（`Building2` `size-8` + 「暂无部门数据」+ 「接入 LDAP 或配置部门映射后展示」）。

### 5.2 隐藏态（E18）

- L2 `ready=false` → ⑧ 区块不渲染（与 PageHeader 部门筛选器一致隐藏；或显示 `SourceGuideState` 说明，见 §1 条件区块规则——**推荐隐藏**，避免重复说明 ⑥⑦ 已覆盖）。

### 5.3 边界（E19）

- 所选部门无成员/无数据 → 相关卡片（热力图/渗透率/⑥⑦）各自空态，部门下拉仍可用；返回「全部」恢复全局口径。
- Agent 不归属任何部门（口径 §1.5）→ 部门切片下 Agent 渗透率分母可能变化，正常渲染。

## 6. 部门联动重查规则（前端逻辑）

| 触发 | 重查接口 | 说明 |
| --- | --- | --- |
| 部门筛选器切换（Tab1 激活） | A1–A5（带 `department_id`） | Tab1 全部模块 |
| 部门筛选器切换（Tab2 激活） | B1（带 `department_id`） | 仅漏斗；B2–B6 无部门维度则缓存 |
| 部门筛选器切换（Tab3/Tab4 激活） | 无 | 不重查、不传参（PRD §4.6） |
| L2 `ready=false` | — | 部门筛选器隐藏（E18） |
| 传 `department_id` 但部门未接入 | 400 | 前端以 `ready=false` 隐藏筛选器规避（API §0.2） |

## 7. 全模块状态矩阵（Tab1 增量部分）

| 模块 | 正常 | 引导态（LDAP 未接入） | 空态（ready=true 无数据） | 加载 | 错误 |
| --- | --- | --- | --- | --- | --- |
| PageHeader 部门筛选器 | 显示+联动 | 隐藏 | 部门无成员（下拉仍可用） | — | 400 时隐藏 |
| ⑥ 用户生命周期卡 | 两指标+事件列表 | `SourceGuideState` | `Empty` 窗口无事件 | Spinner | Alert+重试 |
| ⑦ 权限熔断成功率卡 | 单指标+进度条 | `SourceGuideState` | value `-` 无事件说明 | Spinner | Alert+重试 |
| ⑧ 部门维度切片 | 部门对比列表 | 隐藏 | `Empty` 暂无部门 | Spinner | Alert+重试 |

**异常场景映射**：E18（LDAP 未接入）→ ⑥⑦引导态 + ⑧隐藏 + 部门筛选器隐藏；E19（部门无成员/无数据）→ 相关卡片空态，下拉可用；E7/E8/E9 同 Tab1 v1.0。
