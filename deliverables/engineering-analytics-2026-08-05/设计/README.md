1. **GitCode 线上授权/Webhook 未开通**：当前仅本地部署。Git 模块以**本地仓库分析口径先行**，PR 积压/合并周期依赖 VCS 连接接入或文件导入，需 Leader 确认是否申请线上接入。
2. **ELOC 工具链选型待拍板**：建议二期 Cloc/SCC 行数兜底先行 + AST 当量并行评估（CLO-227 已接受 AST 工具链）。
3. **本地库无部署流水线表**：DORA 需部署事件上报接口/文件导入/手动录入，需研发在部署流程加回调，需 Leader 协调。
4. **本地库无 LDAP/IDP 数据**：用户生命周期/部门维度需 LDAP 同步或手动映射先行；不提供则引导态呈现。
5. **VCS provider 枚举无 GitCode**：接入线上需确认 GitCode 兼容 Gitea 协议或新增 provider，待研发确认。
6. **一期遗留 4 个待确认口径**（见可行性 §6）+ v2.0 新增 6 个（§10），均不阻塞开发，已给建议默认值。
