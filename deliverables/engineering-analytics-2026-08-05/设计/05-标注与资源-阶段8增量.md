## 5. 交互标注（阶段8 增量）

| 交互 | 行为 | 组件 |
| --- | --- | --- |
| ELOC 排行行点击 | → HoverCard 提交明细（SHA/时间/仓库/路径） | `HoverCard` |
| ELOC「按人/按Agent」切换 | → 重拉 G1 `group_by` | `Segmented` |
| 质量雷达仓库下拉 | → 重拉 G2 `repo` | `Select` |
| 代码仓行点击 | → Dialog PR 明细下钻（G4） | `Dialog` + `Table` |
| 交付周期口径切换 | → 重拉 D1 `metric`；不可用自动回落 | `Segmented` + `Badge` |
| 失败明细筛选 | 全部/已恢复/进行中 + MTTR 排序 | `Segmented` / 列头排序 |
| 生命周期卡点击 | → Dialog 事件明细 | `Dialog` |
| 部门筛选器/切片切换 | → Tab1（A1–A5）/Tab2（B1）带 `department_id` 重查 | `Select` / `Progress` |
| 引导态「前往配置」 | → 对应设置路由占位 | `Button`（link） |
