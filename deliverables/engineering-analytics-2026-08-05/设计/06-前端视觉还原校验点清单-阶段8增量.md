# 前端视觉还原校验点清单（阶段8 增量）

> 用途：前端开发完成后的逐页逐模块视觉还原验收依据；Leader 审核放行前由 UI 侧逐项核对。
> 基准：`packages/ui` 组件 + `docs/design.md` token；**任何一项「硬编码」均为不通过**。
> 范围：仅阶段8 增量（Tab3 / Tab4 / Tab1 ⑥⑦⑧ / PageHeader 部门筛选器 / Tab1–Tab2 微调）；v1.0 清单（CLO-236 `06`）原样保留，两清单叠加执行。

---

## 0. 通用硬约束（全站，延续 v1.0）

- [ ] **零硬编码样式**：无 `text-red-500`/`bg-gray-100`/`text-[13px]`/`w-[137px]`/`font-bold`/`shadow-sm`/`scale-105` 等（design.md §10）。
- [ ] 颜色全部用 token（`bg-surface`/`text-muted-foreground`/`bg-chart-1`/`text-success`…）。
- [ ] 字号只在 `text-xs / text-sm / text-base` 范围（图表内部 `text-[10px]/[11px]` 例外沿用 charts 惯例）。
- [ ] 字重只用 `font-normal` / `font-medium`（KPI 卡沿用既有 `font-semibold` 惯例除外）。
- [ ] 间距全部 Tailwind 内置 scale（4px 网格）。
- [ ] 圆角用 `rounded-sm/md/lg/xl/full`。
- [ ] hover 比 active 淡；active 被 hover 时不被覆盖。
- [ ] 图标全 Lucide，尺寸与组件匹配。
- [ ] 动效 `transition-colors` 150-200ms `ease-out`，无 spring/bounce。
- [ ] Light / Dark 双模式验证通过。

## 5. 「数据源未接入」引导态 vs 空态（阶段8 核心校验）

- [ ] **引导态**（`source_status.ready=false`）：`SourceGuideState` 组件 + 「前往配置」按钮；不可渲染为普通空态。
- [ ] **空态**（`ready=true` 且 `[]`）：`Empty` 组件，无配置按钮。
- [ ] `null` → `-`；`0` → 数值零（非空态信号）。
- [ ] 引导态文案逐字核对 PRD §7 汇总表。
- [ ] 「前往配置」按钮为 `Button variant="outline" size="sm"`，每模块 1 个（主操作约束）。
