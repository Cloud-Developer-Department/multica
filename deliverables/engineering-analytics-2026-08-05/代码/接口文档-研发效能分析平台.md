## 0. 通用约定（实现侧）

### 0.1 认证与鉴权

- 会话登录态（JWT cookie / Bearer）+ **工作区成员身份**，由路由组中间件强制。
- 服务端会话用户决定权限，接口不接受前端传入的用户标识。
- 未登录 → `401 {"error":"unauthorized"}`；非成员 → `403`。

### 0.2 请求公共参数

| 参数 | 位置 | 类型 | 必填 | 默认 | 实现行为 |
| --- | --- | --- | --- | --- | --- |
| `days` | query | int | 否 | `30` | 1–365；非法/缺失回退 30（`parseAnalyticsDays`） |
| `tz` | query | string | 否 | 用户已存时区 → UTC | IANA；非法回退 UTC（`resolveViewingTZ` + `LoadLocation`） |
| `project_id` | query | uuid | 否 | 整个工作区 | 格式非法 → `400`（`parseProjectIDParam`） |
| `department_id` | query | string | 否 | 全部 | **仅 Tab1/Tab2/L1 支持**；未配置部门数据时传入 → `400`（E18） |

> 窗口语义：自然日窗口，`tz` 本地 00:00 为日界；`days=30` 覆盖「近 30 个自然日」（含今日）。

### 0.3 响应结构

- 成功 `200` + `application/json`，直接返回数据对象（无包裹层），snake_case。
- 失败统一 `{"error":"<message>"}`。

### 0.4 错误码

| 码 | 场景 |
| --- | --- |
| `400` | `project_id` 格式非法 / 不存在；未接入部门数据时传 `department_id`；G4 缺 `repo` |
| `401` | 未认证 |
| `403` | 非工作区成员 |
| `404` | 路由不存在 |
| `500` | 查询失败（引导态判定错误等，正常情况不触发） |

### 0.5 空值语义

- `null`：指标无有效分母/不可计算（无活跃成员、无 Blocker 样本、VCS/部署/身份数据源未接入、无快照）。前端渲染 `-` / 禁用态。
- `[]`：该维度无数据。前端渲染空态文案。
- `0`：有明确语义的数值零（不是空态信号）。
- **外部数据源未接入 = 正常态**：`200 + source_status.ready=false + reason`，不报错、不 404（§0.7）。

### 0.6 数值与时间格式

- 数量类 `int64`；比率类 `number` 0–1（或 `null`）；时长类 `number` 单位**秒**（或 `null`）；时间 RFC3339；日期 `YYYY-MM-DD`。

### 0.7 外部数据源状态 `source_status`（G/D/L 接口必含）

| 字段 | 类型 | 空值语义 |
| --- | --- | --- |
| `ready` | bool | 数据源可用 |
| `reason` | string \| null | 不可用时人读原因（如「Git 数据源未接入」「部署流水线数据未接入」「用户身份数据源未接入」） |
| `updated_at` | string \| null | 最近一次同步/快照时间 |

实现判定依据：
- **Git 就绪**（G1/G3/G4 + D1-merged）：`vcs_connection` 存在 **或** `workspace.repos` 非空；`updated_at` = `vcs_pull_request.pr_updated_at` 最大值。
- **质量扫描就绪**（G2）：`repo_quality_snapshot` 非空。
- **部署就绪**（D1-deploy/D2）：`deployment_event` 非空。
- **身份就绪**（L1/L2）：`identity_import` 非空 / `member.department` 非空。

| 字段 | 类型 | 空值语义 | 说明 |
| --- | --- | --- | --- |
| `source_status` | object | 恒返回 | §0.7 |

### 接口 L2 `GET /api/analytics/identity/departments`

参数：§0.2（**不含** `department_id`）。

| 字段 | 类型 | 空值语义 | 说明 |
| --- | --- | --- | --- |
| `source_status` | object | 恒返回 | §0.7 |
| `items` | array | `[]`=无数据 | `[{ "department_id": string, "name": string, "member_count": int, "active_members": int }]` |

> 实现口径：`member.department` 非空即视为已接入；`department_id` 与 `name` 均取 `member.department` 值（外部稳定 ID 接入后替换）。`active_members` = 窗口内活跃成员去重数。
> 引导态：无成员配置 `department` → `ready=false + "用户身份数据源未接入"`。此接口 `ready=false` 时前端隐藏部门筛选器与 ⑥⑦⑧ 模块（PRD §1.x）。

---

## 错误响应示例

**400（未接入部门数据时传 department_id）：**
```json
{ "error": "department data not configured" }
```

**400（project_id 非法）：**
```json
{ "error": "invalid project_id" }
```

**400（G4 缺 repo）：**
```json
{ "error": "repo is required" }
```

**401：**
```json
{ "error": "missing authorization" }
```

## 前端联调校准点（CLO-240 ↔ CLO-239）

1. **`source_status` 判定**：G/D/L 接口顶层恒含；`ready=false` 时前端渲染引导态而非空态，且请求真实接口也返回 `200`，前端勿按 4xx/404 处理。
2. **ELOC 人/机分组**：`group_by=member|agent` 只改变 `items` 内容；`human_eloc`/`agent_eloc` 总量恒双写。
3. **雷达反轴归一化参数**：`coverage` / `duplication_rate` 为 0–1 原始值，前端按需反轴归一化，接口不做翻转。
4. **秒→天换算**：`*_seconds` 类字段单位恒为秒；前端按展示需求 `/86400` 换天，接口不换算。
5. **Merged 引导态**：B1 `merged_count=null` 仅因 VCS 未接入；接入后为数值（`0` 表示窗口内无 merged）。
