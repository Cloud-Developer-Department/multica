## 关键口径（速览）

- **归属**：任务发起人 `agent_task_queue.initiator_user_id`（含 autopilot，算在配置人头上）。
- **时间**：今天 / 本周（周一 00:00 起）/ 本月，默认本周，切换全量重查、全页跟随。
- **成本**：服务端回原始拆分（`cost_usd_ticks` + `uncosted_*_tokens`），前端按价目表估算 USD，再 × 实时汇率 → ¥；汇率失败降级默认值（`MULTICA_DASHBOARD_FX_DEFAULT_CNY`，默认 7.2），标注「汇率更新于 xx:xx」。
- **排行榜**：仅返回我的名次 / 总人数 / 超过% / 团队人均 / 团队中位数，**任何情况下不返回他人明细**。
- **终态任务**：`status IN ('completed','failed')`；成功率 = `completed/(completed+failed)`，无终态任务为 `-`。
- **耗时分桶**：`<1m` [0,60) / `1-5m` [60,300) / `5-15m` [300,900) / `15-30m` [900,1800) / `>30m` [1800,∞)。
- **移除模块**：Issue 状态分布、项目进度、评论热度、运行时状态（不再展示）。
