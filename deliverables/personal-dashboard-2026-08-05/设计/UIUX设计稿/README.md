## 设计基线（本套设计遵循）

1. **沿用既有视觉语言**：所有样式取自 `docs/design.md` 设计系统 + `packages/ui/styles/tokens.css` + 现有 `monitoring-dashboard.tsx` 看板风格（KPI 卡、ModuleCard、Segmented、Empty、Skeleton、recharts `ChartContainer`/`ChartTooltip`），**不另起风格**。
2. **8 模块 + 时间切换与 PRD 完全一致**：今天/本周/本月（默认本周），全页跟随切换、并行全量重查。
3. **排行榜隐私硬约束**：排名卡只展示「我的名次/总人数/超过%/团队人均/团队中位数/我的数值」，任何状态下不出现他人消耗数字。
4. **成本展示**：人民币 ¥，实时汇率；降级默认值标注「汇率更新于 xx:xx（默认汇率）」。
5. **移除模块**：Issue 状态分布 / 项目进度 / 评论热度 / 运行时状态，均不出现在设计稿与页面中。

## 关键设计决策（供审核）

1. **模型分布采用「横向占比条形列表」而非饼图**：多模型可读性更好，窄屏无需横滑，且与现有 `PersonalModelsDistribution` 组件一致；配色循环 `--chart-1..5`。
2. **KPI 大数值沿用现有看板 `text-2xl font-bold tabular-nums`**（与 `monitoring-dashboard.tsx` 的 `KpiTile` 一致），属既有看板视觉语言；KPI 区为 5 卡（`xl:grid-cols-5`）。
3. **排名卡为主卡全宽**，三 stat（团队人均/中位数/我的）窄屏纵向堆叠、宽屏三列。
4. **图表切换（Token/成本）仅前端行为**：接口一次返回双序列，切换不重查（PRD §6.2）。
5. **空态文案清单**与 PRD 附录完全对齐（本周暂无消耗/暂无排名/暂无趋势数据/暂无模型数据/暂无耗时数据/暂无运行时长数据/暂无失败数据/暂无错误类型数据）。
6. **整页降级阈值**：≥3 模块同时失败 → 整页错误态 + 重新加载；单模块失败 → 模块级错误 + 重试。
