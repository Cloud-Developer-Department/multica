# 个人用量看板 · 组件规范与标注资源

> 文档编号：UIUX-CLO-215-03
> 版本：v1.0（2026-08-05）
> 设计系统：`docs/design.md`（Multica Design System）+ `packages/ui/styles/tokens.css`（设计 token）+ shadcn 组件库
> 用途：作为前端 1:1 还原的**唯一视觉标准**。所有值均来自 token 与既有组件，禁止硬编码色值/像素值。

---

## 1. 颜色体系

### 1.1 语义色（token，禁止硬编码）

| Token | Light 值（OKLCh） | 本页面用途 |
| --- | --- | --- |
| `--brand` | `oklch(0.55 0.16 255)` | 品牌蓝：Segmented 选中项、Token 折线、耗时柱、模型占比条、主强调 |
| `--success` | `oklch(0.55 0.16 145)` | 成本折线 |
| `--destructive` | `oklch(0.577 0.245 27.325)` | 失败率折线、错误类型占比条、错误态图标 |
| `--warning` | `oklch(0.75 0.16 85)` | （页面主色不使用；若 KPI 成功率做分级色调可参考） |
| `--info` | `oklch(0.55 0.18 250)` | 排名卡名次数字强调（或直接用 brand） |
| `--violet` | `oklch(0.58 0.22 293)` | 备用区分色（勿与 brand 同屏混用） |

> Dark 模式语义色自动由 `.dark` 作用域解析（如 brand→`0.65 0.16 255`），前端只需用 token，无需手写暗色类。

### 1.2 图表色板（多模型可区分）

`MODEL_COLORS`（与 `charts.tsx` 一致）：

| 序 | Token | Light 值 | 用途 |
| --- | --- | --- | --- |
| 1 | `var(--chart-1)` | `oklch(0.55 0.16 255)`（= brand） | token 最多模型（锚定品牌色） |
| 2 | `var(--chart-2)` | `oklch(0.66 0.13 255)` | 运行时长折线、第二模型 |
| 3 | `var(--chart-3)` | `oklch(0.76 0.10 255)` | 第三模型 |
| 4 | `var(--chart-4)` | `oklch(0.85 0.06 255)` | 第四模型 |
| 5 | `var(--chart-5)` | `oklch(0.92 0.03 255)` | 第五模型及之后循环 |

> 规则：图表系列色从 `--chart-*` 取，语义色（brand/success/destructive）只用于单一语义系列。模型列表超过 5 个时按 index 循环取色，保证可区分。

### 1.3 中性色（surface 体系）

| Token | 用途 |
| --- | --- |
| `--page-canvas` / `bg-page-canvas` | 页面背景 |
| `--surface` / `bg-card`（= `bg-surface`） | KPI 卡、ModuleCard 背景 |
| `--surface-border` / `border-border` | 卡片边框 |

| `--foreground` / `text-foreground` | 数值主文字 |

### 1.4 品牌色透出（Segmented 选中）

选中项：`bg-brand text-white shadow-sm`；未选中：`text-muted-foreground hover:text-foreground`（hover 用 `transition-colors`）。

## 2. 字体规范

### 2.1 字号（仅用 3 个核心字号）

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| `text-base` | 16px | 页面标题、排名卡主文案 |
| `text-sm` | 14px | 模块标题、按钮、列表正文（主力） |
| `text-xs` | 12px | KPI label、副行、图表 tooltip 元数据、badge、汇率角标 |

**例外（KPI 数值，沿用现有看板实现）**：KPI 大数值用 `text-2xl font-bold tabular-nums`（与现有 `monitoring-dashboard.tsx` 的 `KpiTile` 一致，属既有看板视觉语言，不视为违背 design.md 通用纪律）。

### 2.2 字重

| 字重 | 用途 |
| --- | --- |
| `font-normal` (400) | 正文、描述、图表标签 |
| `font-medium` (500) | 标题、按钮、Segmented 选中项、数值强调 |

### 2.3 字体族

| 角色 | 字体 |
| --- | --- |
| 正文/UI | Inter（`--font-sans`），CJK fallback PingFang SC / Microsoft YaHei / Noto Sans CJK |
| 代码/数据 | Geist Mono（`--font-mono`）—— 错误类型 `code`、ID 类展示 |
| 数字 | `tabular-nums`（对齐所有 KPI / 图表数值） |

## 5. 图表样式规范（recharts）

统一容器：`ChartContainer`（`@multica/ui/components/ui/chart`），图表尺寸 `aspect-[3/1] w-full`；tooltip 用 `ChartTooltip + ChartTooltipContent`（与现有看板/`charts.tsx` 完全一致）。

| 图表 | 类型 | 系列色 | 特有配置 |
| --- | --- | --- | --- |
| Token/成本趋势 | LineChart | tokens=`var(--brand)` / cost=`var(--success)` | `strokeWidth={2} dot={false}`，metric 切换仅前端 |
| 模型分布 | 横向占比条列表 | `MODEL_COLORS` 循环 | `h-2 rounded-full` 条；`transition-[width] duration-300 ease-out` |
| 耗时分布 | BarChart | `var(--brand)` | `radius={[3,3,0,0]} maxBarSize={48}`；Y `allowDecimals={false}` |
| 总运行时长趋势 | LineChart | `var(--chart-2)` | `strokeWidth={2} dot={false}`；tooltip 含任务数 |
| 失败率趋势 | LineChart | `var(--destructive)` | `domain={[0,100]}`，Y tick 加 `%`，`connectNulls` |
| 错误类型分布 | 横向条形 TOP 列表 | `var(--destructive)` | 条宽按 max count 归一 |

**通用配置**（与现有 `charts.tsx` 一致）：
- `CartesianGrid vertical={false}`
- `XAxis tickLine={false} axisLine={false} tickMargin={8} interval="preserveStartEnd"`
- `YAxis tickLine={false} axisLine={false} tickMargin={8} width={42}`

**Tooltip 内容**：
- 趋势（tokens）：`formatTokens` 千分位 / M
- 趋势（cost）：`¥{x.toFixed(2)}`
- 时长：`{runtimeLabel} · {N} 任务`
- 失败率：`{v.toFixed(1)}%`

## 6. 断点与响应式

| 断点 | 档位 | KPI 卡 | 模块两列 | 排名卡 stat |
| --- | --- | --- | --- | --- |
| 默认（<768px） | 移动 | 2 列 | 单列 | 纵向堆叠 |
| `md` ≥768px | 平板 | 3 列 | 单列 | 纵向堆叠 |
| `xl` ≥1280px | 桌面 | 5 列 | 两列（④⑤/⑥⑦） | 三 stat 横向 |

> 排名卡为主卡，任何断点保持全宽。折线图 `aspect-[3/1]` 在窄屏自然压缩高度，无需横滑容器。

## 9. 数值格式化约定

| 类型 | 格式 | 函数参考 |
| --- | --- | --- |
| token | 千分位；≥1e6 → `X.XX M` | `formatTokens`（`runtimes/utils.ts`） |
| 成本 | `¥{x.toFixed(2)}` | — |
| 成功率/失败率 | 1 位小数 + `%`；null → `-` | `formatRate1`（`monitoring/utils.ts`） |
| 运行时长 | `Xh Ym`（秒→可读） | 前端格式化 |
| 名次/人数 | 整数 | — |
| 超过% | 1 位小数 + `%` | — |
| 汇率时间 | 本地 `HH:mm` | `formatTimeHHMM` |

## 11. 可访问性要点

- Segmented 用 `aria-pressed` 表达选中态；整组可键盘 Tab 导航。
- 图表 `aria-label`：模型分布 `model-distribution`、错误类型 `error-types` 等（沿用 `charts.tsx`）。
- 空态/错误态提供 `role` 语义（shadcn Empty 组件已含 `data-slot`）。
- 数值全部 `tabular-nums` 保证列对齐。
- 对比度：中性文字用 `foreground`/`muted-foreground`，语义色仅用于小面积。
