## 1. 通用卡片状态约定（所有模块一致）

每个数据模块在**自己的卡片壳内**独立渲染状态，任一模块异常不影响其他模块：

```
loading（骨架屏）→ error（模块级错误 + 重试）→ empty（空态文案）→ 正常渲染
```

| 状态 | 视觉实现 | 说明 |
| --- | --- | --- |
| `loading` | `ModuleSkeleton`：`Skeleton h-[220px] w-full rounded-lg` + 3 个点 | 首载 / 时间切换期间；切换时**保留旧数据原地骨架**，不整页白屏（PRD §3.2） |
| `error` | `AlertCircle`（`h-6 w-6 text-destructive`）+ `数据加载失败` + `Button size="sm" variant="outline"`「重试」 | 模块级；触发该模块 `refetch()` |
| `empty` | `Empty` 组件：`EmptyMedia variant="icon"`（`size-8 rounded-lg bg-muted` 图标）+ `EmptyTitle text-sm font-medium` 空态文案（+可选 `EmptyDescription`） | 各模块独立空态文案（§2.2） |
| 正常 | 渲染数据 / 图表 | — |

**整页级降级**：≥3 个模块同时失败 → 判定后端不可达 → 整页错误态：

```
AlertCircle（h-10 w-10 text-destructive）
数据加载失败 · 请稍后重试或检查网络连接
[重新加载] Button variant="outline"
```

## 2. 各模块状态矩阵

### 2.1 正常态 → 数据渲染

对应 `01-全页面设计稿.md` 各模块正常样式。展示口径一览：

| 模块 | 正常态关键展示 |
| --- | --- |
| ① KPI | 5 卡数值：Token 千分位/M 后缀、¥ 成本 2 位小数、任务数、运行时长 `Xh Ym`、成功率 1 位小数% |
| ② 排名 | `{范围}你排 第 N 名 / 共 M 人，超过 X% 成员` + 人均/中位数/我的 三 stat |
| ③ 趋势 | 折线（Token/成本切换），空桶补 0 连续 |
| ④ 模型 | 占比条形列表，token 降序 |
| ⑤ 耗时 | 5 桶直方图 |
| ⑥ 时长 | 折线 + tooltip 任务数 |
| ⑦ 失败率 | 折线 domain 0–100，null 点断开 |
| ⑧ 错误类型 | TOP 列表 count·pct 降序 |

### 2.2 空数据态（empty）—— 文案清单

> 空态判定以 **API 契约空值语义**（null / [] / 0）为准，见 `API契约` §0.4。

| 模块 | 判定条件 | 空态文案 | 图标建议（Lucide） |
| --- | --- | --- | --- |
| ① KPI | `token_total===0 && task_count===0` | `{今天/本周/本月}暂无消耗` | `Inbox` |
| ② 排名 | `rank === null`（本人无终态任务） | `暂无排名` | `Trophy` / `TrendingUp` |
| ③ 趋势 | `points` 为空数组 | `暂无趋势数据` | `LineChart` |
| ④ 模型 | `items` 为空数组 | `暂无模型数据` | `Layers` |
| ⑤ 耗时 | `total === 0` | `暂无耗时数据` | `Timer` / `Clock` |
| ⑥ 时长 | `points` 为空数组 | `暂无运行时长数据` | `Activity` |
| ⑦ 失败率 | `trend` 为空数组 | `暂无失败数据` | `AlertTriangle` |
| ⑧ 错误类型 | `types` 为空数组 | `暂无错误类型数据` | `Bug` |

> 图标仅供参考；沿用 shadcn `Empty` 组件图标位，最终以 Lucide 既有可用项为准（禁用额外图标库）。

### 2.3 特殊边界态（数字语义）

| 场景 | 判定 | 展示 |
| --- | --- | --- |
| 成功率无终态任务 | `success_rate === null` | 成功率卡显示 `-` |
| 失败率无终态任务 | `failure_rate === null` | 模块⑦显示 `-`（整体） |
| 排名无人（M=0） | `total_members===0` | 排名卡「暂无排名」或「共 0 人」；人均/中位数为 `—` |
| 只有自己（M=1） | `total_members===1` | `第 1 名 / 共 1 人`，超过 0%，人均=中位数=本人值 |
| 团队聚合缺失 | `team_avg/team_median === null` | 对应 stat 显示 `—` |
| 模型未匹配价目表 | `priced` 为假（前端推导） | 模型名后「未定价」badge；成本按 0 计；token 照常 |
| 空桶 | 桶值 0 | 趋势补 0 连续；直方图 count=0 |
| 汇率不可用且无默认值 | `/rates` 返回 500 | 成本相关模块走 error 态；工具栏汇率角标不展示 |

## 3. 汇率降级标注设计

**数据源**：`GET /api/dashboard/rates` → `{rate, source, updated_at, default_rate}`

| source | 角标文案 | 位置 |
| --- | --- | --- |
| `live` | `汇率更新于 14:30`（`updated_at` 转本地 HH:mm） | 工具栏（Clock 图标前置）+ 成本 KPI 卡副行 |
| `default` | `汇率更新于 xx:xx（默认汇率）`（或省略时间，仅示「默认汇率」） | 同上，**成本按 `rate`（默认 7.2）换算** |
| `/rates` 加载中 | 不展示角标（或 `—`） | — |
| `/rates` 失败（500） | 不展示角标；成本模块按 error 态处理 | — |

**设计规则**：
- 全页**统一从 `/rates` 取一次生效汇率**做全部 ¥ 换算，保证「成本 ÷ 展示汇率」一致（数据口径 §4.4）。
- 降级不阻断其余模块，仅文案标注差异。
- 角标为**信息展示**，非告警，配色用中性色（`text-muted-foreground`），不使用 destructive。

## 4. Loading 态（骨架屏）规范

- 首载 & 时间切换：各模块 `ModuleSkeleton`（`Skeleton h-[220px] w-full rounded-lg` + 3 圆点）。
- KPI 区 loading：5 卡内数值位显示骨架条或 `--`（首载），切换时保留旧数值原地骨架。
- 工具栏刷新中：刷新按钮显示旋转图标 + 「刷新中」，其余不额外遮盖。
- 骨架使用 `Skeleton` 组件（`bg-muted` 渐隐），禁止自定义闪烁动画（见 `docs/design.md` §10 反模式：优先骨架/内联 loading）。

## 5. Error 态规范

| 层级 | 触发条件 | 表现 |
| --- | --- | --- |
| 模块级 | 单个接口失败（≤2 模块） | 该模块卡内 `AlertCircle + 数据加载失败 + [重试]` |
| 整页级 | ≥3 模块同时失败 | 整页错误态 + `[重新加载]` |
| 401 未登录 | 任意接口 401 | 前端跳转登录页 |
| 403 非成员 | 403 | 提示无权限（沿用工作区路由组拦截） |
| 400 参数异常 | `range` 之外异常 | 按模块错误态处理（`range` 非法本身回退默认不报错） |

**重试行为**：模块级重试仅 refetch 该模块；整页「重新加载」refetch 全部 8 接口。

## 6. 状态切换时序（时间切换）

```
用户点击「本月」
  ├─ 立即：记录最新 range，全量并行请求 8 接口（并发）
  ├─ 期间：各卡片保留上一窗口数据 + 骨架屏（不整页白屏）
  ├─ 竞态：以最后一次切换为准，过期响应丢弃（AbortController/请求序号）
  └─ 返回：逐模块原位更新；图表切换项（Token/成本等）保持不变
```

## 8. 隐私状态专项校验（排行榜）

排名卡在**任何状态**下都不得出现他人消耗数字：

- ✅ 正常态：第 N 名 / 共 M 人 / 超过 X% / 团队人均 / 团队中位数（匿名） / 我的 token
- ✅ 空态（无任务）：「暂无排名」+ 人均/中位数 `—`
- ✅ 边界：只有自己 / 共 0 人
- ❌ 禁止：他人 token 数值、他人成本、他人名次明细列表、团队明细排行
