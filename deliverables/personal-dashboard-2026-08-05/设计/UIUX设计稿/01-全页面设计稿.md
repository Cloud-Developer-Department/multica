## 1. 页面定位

单页改造现有 `/{slug}/dashboard`（路由 `apps/web/app/[workspaceSlug]/(dashboard)/dashboard/page.tsx`），从「平台运营视角」改为「开发者个人用量看板」。

- **默认视角**：当前登录用户"我自己"的消耗；**他人的具体消耗数字一律不展示**。
- **默认时间窗**：本周（`week`），顶部可切换 今天/本周/本月，全页跟随切换、并行全量重查。
- **成本展示**：人民币（¥），实时汇率换算；汇率失败降级默认值并标注。
- **页面标题**：`个人用量看板`（PageHeader）。

## 2. 顶部时间切换（SegmentedControl）

**组件**：复用 `monitoring-dashboard.tsx` 内 `Segmented`（`bg-muted` 容器 + `bg-brand text-white shadow-sm` 选中项）。

| 项 | 规格 |
| --- | --- |
| 选项 | 今天 / 本周 / 本月 |
| 默认 | 本周 |
| 选中态 | `bg-brand text-white shadow-sm` + `font-medium` |
| 未选中态 | `text-muted-foreground hover:text-foreground` |
| 尺寸 | `px-2.5 py-1 text-xs font-medium`，容器 `gap-0.5 rounded-md bg-muted p-0.5` |
| 语义值 | `today` / `week` / `month`（映射 API `range` 参数） |
| 切换行为 | 全页 8 模块并行全量重查；切换期间保留旧数据 + 骨架屏，不整页白屏；**不改变各模块图表切换项** |

> 切换竞态：以最后一次切换为准，过期响应丢弃（前端以请求序号 / AbortController 处理，见 PRD §7 E13）。

**工具栏右区（从左到右）**：

1. **汇率角标**：`text-xs text-muted-foreground`，前置 `Clock` 图标（`h-3.5 w-3.5`）。
   - 实时：`汇率更新于 14:30`（HH:mm，本地时区）。
   - 降级：`汇率更新于 xx:xx（默认汇率）`。
   - 加载中/不可得：不渲染角标或显示 `—`（不阻断其他模块）。
2. **刷新按钮**：`Button size="sm" variant="default"`，前置 `RefreshCw`（`h-3.5 w-3.5`）；刷新中显示 `animate-spin` + 文案「刷新中」。手动刷新节流 ≥2s。

## 3. 模块① KPI 卡（我的数据）

**接口**：`GET /api/dashboard/personal/summary`

**容器**：`section.grid grid-cols-2 gap-3 md:grid-cols-3 xl:grid-cols-5`（5 张卡；窄屏 2 列 → 中屏 3 列 → 宽屏 5 列）。

**卡片样式**（复用现有 `KpiTile`）：

```
rounded-lg border bg-card p-4 shadow-sm transition-shadow hover:shadow-md
├─ 顶行：text-xs text-muted-foreground（label，可带 accentDot）
└─ 数值：text-2xl font-bold tabular-nums（foreground；无数据时 text-muted-foreground）
     └─ 副行：text-xs text-muted-foreground
```

| 卡 | Label | 数值格式 | 副行 | 单位/精度 |
| --- | --- | --- | --- | --- |
| 1 | Token 消耗 | `97,000,000`（千分位）；≥1e6 显示 `97.00 M` | — | 精确整数（接口返回 int） |
| 2 | 成本（¥） | `¥132.14` | `汇率更新于 14:30`（来源 `/rates`） | 2 位小数 |
| 3 | 任务数 | `42` | — | 终态任务数（completed+failed） |
| 4 | 运行时长 | `3h 40m` | — | 秒 → `Xh Ym` 可读格式 |
| 5 | 成功率 | `88.1%` | — | 1 位小数；无终态任务显示 `-` |

**空态判定**：`token_total === 0 && task_count === 0` → KPI 区整体空态「**本周暂无消耗**」（文案随范围：今天/本周/本月暂无消耗），各卡数值展示 `0` / `-`。
**异常态**：接口失败 → 5 卡数值均 `—`（MISSING）+ 模块级错误 + 重试。

> 参考 `formatTokens`（`packages/views/runtimes/utils.ts`）、`MISSING = "—"`、`formatRate1`、`formatTimeHHMM`（`packages/views/dashboard/monitoring/utils.ts`）。

## 4. 模块② 我的排名卡（全宽）—— 隐私重点

**接口**：`GET /api/dashboard/personal/rank`

**卡片**：全宽 `ModuleCard`（`rounded-lg border bg-card p-5 shadow-sm`）。

**布局**（三栏，窄屏堆叠）：

```
┌─ 我的排名 ──────────────────────────────────────────────┐
│ 本周你排 第 3 名 / 共 12 人 · 超过 81.8% 成员             │
│                                                         │
│   [团队人均 15.42M]  [团队中位数 9.80M]  [我的 48.00M]   │
└─────────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
| --- | --- |
| 主文案 | `{今天/本周/本月}你排 第 N 名 / 共 M 人，超过 X% 成员`；`text-base font-medium`；名次数字可 `text-brand` 强调 |
| 团队聚合（匿名） | 3 个 stat 块：`团队人均 token`、`团队中位数 token`、`我的 token`（本人值，允许展示）；label `text-xs text-muted-foreground` + 值 `text-lg font-medium tabular-nums` |
| 空态 | 本人无终态任务 → 显示「**暂无排名**」，不展示"第 N 名"；人均/中位数为 null → `—` |
| 边界 | 只有自己 M=1 → `第 1 名 / 共 1 人`，超过 0%；M=0 → 仅「暂无排名」或「共 0 人」，聚合不展示 |

**隐私硬性要求**：
- **界面不渲染任何他人的消耗数字**（无他人 token、成本、他人名次列表）。
- 只展示：我的名次 / 总人数 / 超过百分比 / 团队人均 / 团队中位数（匿名聚合） / 我的数值。
- 接口层已保证不返回他人明细，前端即使拿到也不渲染（PRD §9 强制）。

## 5. 模块③ Token/成本趋势图（全宽折线）

**接口**：`GET /api/dashboard/personal/trend?metric=`

**图表**：`PersonalTrendChart`（`charts.tsx`），recharts `LineChart`，`ChartContainer className="aspect-[3/1] w-full"`。

**切换项**：`Token` / `成本`（模块头 SegmentedControl 或右侧 switch），**默认 Token**；切换即时生效，**不发请求**（接口一次返回双序列）。

| 系列 | 颜色 | 说明 |
| --- | --- | --- |
| tokens | `var(--brand)` | 每桶 token 总数 |
| cost | `var(--success)` | 每桶人民币成本（前端换算：USD×/rates） |

- 分桶：`today` → 小时桶；`week`/`month` → 天桶。空桶补 0，折线连续。
- Tooltip：值 + 桶标签；成本 tooltip 可同时展示 USD 参考值。
- 空态：「**暂无趋势数据**」（`points` 为空数组）。

## 6. 模块④ 模型分布（占比列表，可切 Token/成本）

**接口**：`GET /api/dashboard/personal/models`

**图表**：`PersonalModelsDistribution` —— **横向占比条形列表**（非饼图，保证多模型可读性与窄屏降级）。

**切换项**：`Token` / `成本`（默认 Token，即时切换不重查）。

**行结构**：

```
[●] model-name [未定价?]   ┃██████████░░░░░░┃   60.00M · 62%
```

| 列 | 内容 | 规格 |
| --- | --- | --- |
| 1 | 色点 + 模型名（+「未定价」badge `rounded-sm bg-muted px-1 py-px text-[10px] text-muted-foreground`） | `text-xs`，truncate |
| 2 | 占比条：`h-2 rounded-full bg-muted` 内层 `h-full rounded-full`，宽度 = pct% | `transition-[width] duration-300 ease-out` |
| 3 | 数值 · 占比：`{formatTokens(tokens)} · {pct}%` 或 `¥{cost.toFixed(2)} · {pct}%` | `text-xs tabular-nums text-muted-foreground text-right` |

- **配色**：`MODEL_COLORS = [var(--chart-1), var(--chart-2), var(--chart-3), var(--chart-4), var(--chart-5)]`，按 index 循环；`chart-1` 与 brand 同色保证最重模型锚定品牌色。
- **排序**：按 token 总量降序。
- **未匹配价目表模型**：归入「未定价 / unmapped」分类，token 正常展示，成本按 0 计；仍显示其行。
- **空态**：「**暂无模型数据**」（`items` 为空数组）。

## 7. 模块⑤ 耗时分布（直方图）

**接口**：`GET /api/dashboard/personal/duration`

**图表**：`PersonalDurationHistogram` —— recharts `BarChart`，`aspect-[3/1]`。

| 项 | 规格 |
| --- | --- |
| 分桶（固定 5） | `<1m` / `1-5m` / `5-15m` / `15-30m` / `>30m`（接口恒返回 5 桶，空桶 count=0） |
| 柱色 | `var(--brand)`，`radius={[3,3,0,0]}`，`maxBarSize={48}` |
| Y 轴 | `allowDecimals={false}`（整数任务数） |
| 口径 | 仅计入有 started_at 与 completed_at 的终态任务 |
| 空态 | 「**暂无耗时数据**」（`total === 0`） |

## 8. 模块⑥ 总运行时长趋势（折线）

**接口**：`GET /api/dashboard/personal/runtime-trend`

**图表**：`PersonalRuntimeTrendChart` —— 折线 `var(--chart-2)`，`aspect-[3/1]`。

- 分桶与模块③一致（today 小时 / week·month 天），空桶补 0。
- Tooltip：`时长 · N 任务`（如 `3h 40m · 6 任务`）。
- 空态：「**暂无运行时长数据**」（`points` 为空数组）。

## 9. 模块⑦ 失败率趋势（折线）

**接口**：`GET /api/dashboard/personal/errors`（`trend` 部分）

**图表**：`PersonalFailureRateChart` —— 折线 `var(--destructive)`，`YAxis domain=[0,100]`，tick 格式化 `%`。

- 纵轴：失败率（%），1 位小数。
- 某桶无终态任务 → 该点 `null`（`connectNulls` 断开，不绘制断点）。
- 窗口整体无终态任务 → `-`。
- 空态：「**暂无失败数据**」（`trend` 为空数组）。

## 10. 模块⑧ 错误类型分布（TOP 列表，全宽）

**接口**：`GET /api/dashboard/personal/errors`（`types` 部分）

**图表**：`PersonalErrorTypesList` —— 横向条形 TOP 列表。

**行结构**：

```
agent_error.provider_quota_limit  ┃████████████░░░░┃  3 · 60.0%
```

| 列 | 内容 | 规格 |
| --- | --- | --- |
| 1 | 错误类型 `code`（`taskfailure` 规范值 / `unclassified` 兜底） | `text-xs text-muted-foreground`，truncate |
| 2 | 占比条（相对最大失败次数归一） | 填充 `var(--destructive)` |
| 3 | `{count} · {pct}%` | `text-xs tabular-nums text-muted-foreground text-right` |

- **排序**：按失败次数降序。
- **空态**：「**暂无错误类型数据**」（`types` 为空数组，即无失败任务）。

## 11. 移除模块确认

以下 4 个旧模块**不在新页面出现**（CLO-206 §二.5 / PRD §8）：
