# 接口文档：个人用量看板（后端实现 · 与契约一致）

> 本文档与 `../设计/API契约-个人用量看板.md`（API-CLO-211 v1.1）字段级一致，是后端实现的传输契约说明。
> 指标口径见 `../设计/数据口径说明.md`（CALC-CLO-211）。

## 0. 通用约定

- 认证：JWT cookie 或 Bearer，中间件注入 `X-User-ID`；所有接口要求工作区成员身份。
- **个人接口（1–7）不接受/忽略前端传入的 `user_id`**，一律以服务端会话用户为准。
- `range`：`today|week|month`，缺失或非法回退 `week`，不报 4xx。
- `tz`：IANA 时区，非法回退用户时区→UTC。
- 窗口语义：`today`=今日 00:00→现在；`week`=本周一 00:00→现在；`month`=本月 1 日 00:00→现在（按 tz 本地时区）。
- 成功返回直接是数据对象（无包裹层）；失败为 `{"error":"<消息>"}`。
- 空值语义：`null`=无有效分母/不可计算；`[]`=无数据；`0`=有明确语义的数值零。
- 数值精度：token/时长/成本分片为整数；百分比保留 1 位小数；时间为 RFC3339 UTC。

## 1. GET /api/dashboard/personal/summary

请求：`?range=&tz=`

| 字段 | 类型 | 空值语义 | 说明 |
| --- | --- | --- | --- |
| `range` | string | — | 生效 range |
| `token_input` / `token_output` / `token_cache_read` / `token_cache_write` | number | 0 | 四分量之和（同 `token_total`） |
| `token_total` | number | 0 | 四项之和 |
| `cost_usd_ticks` | number | 0 | 供应商上报成本之和（1e-10 USD） |
| `uncosted_input_tokens` / `uncosted_output_tokens` / `uncosted_cache_read_tokens` / `uncosted_cache_write_tokens` | number | 0 | 未上报成本行的各 token 分量 |
| `task_count` | number | 0 | 终态任务总数（completed+failed） |
| `completed_count` / `failed_count` | number | 0 | 成功/失败数 |
| `run_seconds` | number | 0 | 终态任务时长之和（秒） |
| `success_rate` | number\|null | **null**（无终态任务） | `completed/(completed+failed)×100`，1 位小数 |

示例：
```json
{
  "range": "week", "token_input": 45000000, "token_output": 12000000,
  "token_cache_read": 35000000, "token_cache_write": 5000000, "token_total": 97000000,
  "cost_usd_ticks": 150000000000,
  "uncosted_input_tokens": 12000000, "uncosted_output_tokens": 3000000,
  "uncosted_cache_read_tokens": 8000000, "uncosted_cache_write_tokens": 1500000,
  "task_count": 42, "completed_count": 37, "failed_count": 5,
  "run_seconds": 12900, "success_rate": 88.1
}
```

空态判定（前端）：`token_total === 0 && task_count === 0` → 「{今天/本周/本月}暂无消耗」；`success_rate === null` → 成功率显示 `-`。

## 2. GET /api/dashboard/personal/trend

请求：`?range=&tz=&metric=`；`metric=tokens|cost`（默认 tokens，仅前端初始化用，响应恒返回全部序列）。

分桶：`today` → 小时桶（0 点→当前小时）；`week`/`month` → 天桶。全窗口零填充。

| 字段 | 类型 | 空值语义 | 说明 |
| --- | --- | --- | --- |
| `range` | string | — | 生效 range |
| `points` | array | **`[]`** | 时间序列 |

`points[]`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `time` | string | 桶起点 ISO（RFC3339 UTC） |
| `tokens` | number | 该桶 token 总数 |
| `cost_usd_ticks` | number | 该桶供应商上报成本（1e-10 USD） |
| `uncosted_input_tokens` / `uncosted_output_tokens` / `uncosted_cache_read_tokens` / `uncosted_cache_write_tokens` | number | 未上报成本行分量 |
| `task_count` | number | 该桶任务数 |

示例：
```json
{
  "range": "week",
  "points": [
    { "time": "2026-08-03T00:00:00Z", "tokens": 12000000, "cost_usd_ticks": 15000000000, "uncosted_input_tokens": 3000000, "uncosted_output_tokens": 800000, "uncosted_cache_read_tokens": 2000000, "uncosted_cache_write_tokens": 400000, "task_count": 6 }
  ]
}
```

空态判定：`points` 为空数组 → 「暂无趋势数据」。

## 4. GET /api/dashboard/personal/duration

请求：`?range=&tz=`

分桶（秒，下含上不含）：`<1m`=[0,60)；`1-5m`=[60,300)；`5-15m`=[300,900)；`15-30m`=[900,1800)；`>30m`=[1800,∞)。

| 字段 | 类型 | 空值语义 | 说明 |
| --- | --- | --- | --- |
| `range` | string | — | 生效 range |
| `total` | number | 0 | 计入分布的终态任务数（= Σ buckets.count） |
| `buckets` | array | 恒 5 项 | 空桶 count=0 |

`buckets[]`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `bucket` | string | `"<1m"` / `"1-5m"` / `"5-15m"` / `"15-30m"` / `">30m"` |
| `label` | string | `<1分钟` / `1-5分钟` / `5-15分钟` / `15-30分钟` / `>30分钟` |
| `min_seconds` | number | 下界（含） |
| `max_seconds` | number\|null | 上界（不含）；末桶为 null |
| `count` | number | 该桶任务数 |

空态判定：`total === 0` → 「暂无耗时数据」。

## 8. GET /api/dashboard/rates

请求：无 query 参数（`?tz=` 忽略）。

| 字段 | 类型 | 空值语义 | 说明 |
| --- | --- | --- | --- |
| `rate` | number | — | 生效汇率（USD→CNY，4 位小数） |
| `source` | string | — | `"live"`（实时成功）\| `"default"`（降级默认值） |
| `updated_at` | string\|null | **null**（source=default） | 实时汇率最近成功拉取时间（RFC3339 UTC） |
| `default_rate` | number | — | 配置默认汇率（默认 7.2） |

示例：
```json
{ "rate": 7.1800, "source": "live", "updated_at": "2026-08-05T01:30:00Z", "default_rate": 7.2 }
{ "rate": 7.2000, "source": "default", "updated_at": null, "default_rate": 7.2 }
```

前端使用：页面加载请求一次（60s 内复用）；`source=live` 标注「汇率更新于 updated_at（本地 HH:mm）」；`source=default` 标注「汇率更新于 xx:xx（默认汇率）」。

## 9. 错误码

| HTTP | 语义 | 响应体 |
| --- | --- | --- |
| 401 | 未认证 | `{"error":"user not authenticated"}` |
| 403/404 | 非成员/资源不存在 | `{"error":"<消息>"}` |
| 400 | 参数非法（`range`/`tz` 例外，回退默认不报错） | `{"error":"<消息>"}` |
| 500 | 服务端聚合异常 | `{"error":"failed to load ..."}` |

> 汇率拉取失败不报错，返回 `200` + `source=default`；默认值未配置且拉取失败才会 500（当前实现始终有默认值 7.2，故不会发生）。

## 10. 时间序列一致性

同一 `range` 下，接口 2/5/6 使用同一 `personalBucketAxis`（同 tz 切分、同零填充），保证前端图表并排不错位。
