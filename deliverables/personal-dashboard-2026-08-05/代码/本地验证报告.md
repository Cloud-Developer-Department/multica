## 4. 数据表/查询

- 个人统计从 `task_usage` 直查 + `agent_task_queue`（`initiator_user_id`/`completed_at`）关联聚合，**不依赖 `task_usage_hourly`**（符合 CLO-206 §六）。
- SQL 全部经 sqlc 生成（`server/pkg/db/queries/personal_usage.sql` → `server/pkg/db/generated/personal_usage.sql.go`），12 条查询函数齐全。
