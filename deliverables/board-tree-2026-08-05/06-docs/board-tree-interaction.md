# 看板视图树状交互说明（Board Tree）

**适用版本**: feature/board-tree（看板树状结构）
**读者**: 使用 Multica 看板（Board）视图的用户
**日期**: 2026-08-06

---

## 1. 看板现在长什么样

看板（Board/Kanban）每列内的父子 issue 不再平铺成独立卡片，而是**以树形嵌套展示**：

```
┌── 父任务 A（带 Chevron ▼ + 进度环 2/3）─────────────┐
├──   └─ 子任务 A-1（缩进 1 级）                        │
├──   └─ 子任务 A-2（缩进 1 级）                        │
├──   └─   └─ 孙任务 A-1.1（缩进 2 级，子任务之孙）      │
└── 根任务 B（无子任务，无 Chevron）────────────────────┘
```

- **根任务** = 没有父 issue 的任务；**子任务** 在父卡下方**缩进显示**（每级缩进 18px）。
- 父卡**保留子任务进度环**（`x/y done`），与改动前一致。
- 树的层级可以有多级（子 → 孙 → …），规则相同。

> 开启/关闭树形：看板视图右上角「显示子 issue」开关（`showSubIssues`）。关闭后只看根任务，等同旧版过滤模式。

## 2. 展开 / 折叠

- 有子任务的父卡左上角会出现一个 **Chevron 箭头**（`▼` 展开 / `▶` 折叠）。
- 点击箭头：**展开**时子任务缩进显示在父卡下方；**折叠**时整棵子树收起，只留父卡（子任务不占位、不渲染）。
- 无子任务的卡片**不显示箭头**。
- 折叠状态是**持久化的**（刷新、切换视图后保留），并且**与表格视图独立**——你在看板折叠了 A，切到表格视图不会看到 A 也被折叠。

> 性能提示：子任务很多时建议折叠不关注的父卡，减少列内卡片数量。

## 3. 拖拽语义（重点）

看板拖拽遵循**统一规则：「拖什么 = 移动什么及其全部子级」**。这张表记住即可：

| 你拖的卡片 | 结果 |
|-----------|------|
| **父卡（有子任务）** | 整棵子树一起移动：同列排序整组走、跨列整组换状态/负责人 |
| **叶子子任务（无子级）** | 单独移动（它就是"只有自己"的子树） |
| **子任务跨列拖出父卡所在列** | **脱离父任务**：变成目标列的顶层任务（`parent_issue_id` 置空），其自身的子级仍跟随它 |
| **子任务拖到别的卡片上（同列内）** | 仅在该列内调整位置，不脱离父任务 |

拖拽时被拖卡片会浮起预览，预览下方有两个**徽章**：

- `子任务 +N`：这次拖动会连带 N 个子任务一起移动。
- `将转为顶层任务`（琥珀色）：当被拖的卡片本身是子任务、且这次拖动会脱离父任务时出现。

### 3.1 三种典型操作

**① 父卡同列排序**
把父卡在列内上移/下移 → 整棵子树一起挪动。只调整位置，不改状态/负责人。

**② 父卡跨列移动（状态 / 负责人分组）**
把父卡拖到另一列 → 父卡进入目标列，**所有子任务状态/负责人随之同步**到目标列（跟随父列，见第 4 节）。
> 同步失败时：父卡已就位，子任务状态未变，界面会提示「部分子任务状态未同步」，可刷新或重拖。

**③ 子任务单独移动**
把子任务拖到目标列 → 该子任务脱离父任务，成为目标列独立顶层任务。它的子级（若有）仍跟着它。

### 3.2 排序模式说明

- 看板按**手动排序**（position）时，同列拖拽=重排，跨列=改列+定位。
- 看板按**其他字段排序**（如创建时间）时，同列拖拽无效（顺序由排序字段决定），跨列仍可改列。

### 3.3 属性（select 类型）分组列的特别说明

- 按自定义属性分组时，**跨列移动只移动父卡本身**（属性值走既有单卡路径），子任务**不级联改属性**，但子任务仍跟随父列显示。
- 这是 v1 的已知限制（见 Release Note「已知限制」），后续版本会演进。

---

## 4. 子任务跟随父列

- 子任务**显示在父卡所在列**，无论子任务自己的状态/负责人/属性值是什么。
  - 例如：父任务在 `Done` 列，它的子任务即使状态还是 `In Progress`，也显示在 `Done` 列（跟在父卡下面）。
- 仅当**父卡不可见**时（父被过滤掉 / 不在当前分页 / 没有父）子任务才按**自己的**状态/负责人落列，作为该列的根任务。

> 这与表格视图的 hierarchy 语义保持一致：层级展示的归属由父决定。

## 5. 常见问题（FAQ）

**Q1：为什么我拖子任务到别的列，它的父任务没有跟着变？**
因为拖拽规则是「你拖哪张卡就移动哪张卡及其子级」——子任务不是父的"子级里的父"，它移动只会带走它自己的子级，不会反向带动父任务。

**Q2：折叠后我的子任务去哪了？**
只是隐藏了，数据没动。点击父卡 `▶` 展开即可恢复显示。

**Q3：子任务显示错列了？**
先检查它的父任务在不在当前视野的某个列里——子任务永远跟随父列显示。如果父被过滤/分页掉了，它才按自己的状态列。

**Q4：怎么批量把子任务全部改状态？**
拖父卡跨列即可：父卡移动后所有子任务状态/负责人自动同步到目标列。
