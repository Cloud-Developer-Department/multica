## 新功能

- **看板列内父子任务树形展示**：父任务卡片可展开/折叠，子任务缩进显示在父卡下方，支持多级嵌套。
- **统一拖拽语义「子树移动」**：
  - 拖父卡 = 整棵子树一起移动（同列排序 / 跨列改状态与负责人）；
  - 拖叶子子任务 = 单独移动；
  - 拖子任务跨列 = 脱离父任务，成为目标列顶层任务。
- **子任务跟随父列**：子任务始终显示在父卡所在列，不受自身状态/负责人/属性值影响；仅当父不可见时按自身值落列。
- **拖拽预览徽章**：拖动时显示「子任务 +N」和「将转为顶层任务」提示，提前告知拖动效果。
- **折叠状态持久化**：展开/折叠状态随视图保存，且与表格视图的折叠状态相互独立。

## 交互变化（相对上一版本）

| 行为 | 之前 | 现在 |
|------|------|------|
| 看板内父子展示 | 平铺为独立卡片 | 树形嵌套、可展开/折叠 |
| 拖父卡 | 只移动父卡 | 整棵子树一起移动 |
| 拖子任务跨列 | 作为独立卡片移动 | 脱离父任务转顶层（预览有提示） |
| 子任务列归属 | 按自身状态/负责人 | 跟随父列显示 |
| 折叠状态 | 无 | 持久化、与表格视图独立 |

## 技术要点

- 纯前端实现，后端 API 零改动、无数据库迁移。
- 复用数据层 `childProgressMap`（进度环 + 「有子」信号）与 `childrenByParentsOptions`（分页边界惰性补拉）。
- Table / List / Swimlane 视图行为不受影响。

## 已知限制

- 属性（select）分组列：跨列移动仅父卡变更属性值，子任务不级联（v1 限制，后续演进）。
- 拖父跨列时子任务批量状态同步为两阶段写入，极端情况下子任务可能未同步（界面会提示，可重拖）。
- 后端批量更新不支持手动排序位置同步，子任务在新列按自然顺序排列。
