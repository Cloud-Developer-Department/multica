# 反馈中心 — 系统使用说明

> 适用版本：反馈中心 v1.0（2026-08-13）。本文面向 Multica 的普通用户，介绍如何进入反馈中心、浏览、搜索、筛选、提交反馈、点赞与评论。

## 1. 入口

反馈中心有**两个入口**，指向同一个页面：

1. **左侧一级导航「💬 反馈」**：登录工作区后，在左侧导航中与 Issues、项目、自动化、智能体、小队、用量同级的位置点击「反馈」。
2. **底部帮助菜单「反馈」**：点击左下角帮助（❓）菜单中的「反馈」。

> 未登录时访问反馈中心，会先按现有机制跳转到登录页；登录后回到反馈中心。

## 2. 浏览反馈列表

反馈中心列表页顶部为标题「反馈中心」、副标题与右侧「+ 提交反馈」按钮。下方依次是：

1. **类型筛选 Tab**：全部 / 问题反馈 / 功能建议 / 体验优化 / 其他。点击某个类型仅显示该类型的反馈。
2. **搜索框「搜索反馈……」**：输入关键词后自动（防抖）按标题 + 描述模糊匹配。
3. **排序下拉**：最新（默认）/ 最热门 / 评论最多。

列表中的每条**反馈卡片**包含：点赞数、标题、描述摘要、类型标签、创建者、创建时间、评论数。滚动到底部自动加载更多。

- 没有反馈时显示「还没有反馈 / 成为第一个告诉我们如何改进 Multica 的人。」
- 搜索无结果时显示「没有找到相关反馈 / 尝试更换关键词或筛选条件。」
- 加载失败时显示「加载反馈失败」+ [重新加载]。

## 3. 查看反馈详情

点击任一反馈卡片进入详情页：

- 顶部「← 返回反馈中心」返回列表；
- 左侧为「👍 支持 / 已支持」点赞按钮（显示当前点赞数）；
- 反馈标题、类型标签、创建者、创建时间；
- 完整问题描述；
- 评论列表（头像、用户名、内容、时间）；
- 底部为「发表评论……」输入区（仅登录用户显示）。

反馈不存在时显示「未找到该反馈」。

## 4. 提交反馈（需要登录）

点击列表页「+ 提交反馈」（或空状态下的「提交第一个反馈」）打开提交弹窗，填写：

| 字段 | 说明 | 限制 |
|---|---|---|
| 反馈类型 | 问题反馈 / 功能建议 / 体验优化 / 其他 | 必选，默认功能建议 |
| 标题 | 一句话概括你的反馈 | 必填，≤200 字符 |
| 详细描述 | 详细描述遇到的问题或建议 | 必填，≤10000 字符 |

点击「提交」。成功后弹窗关闭并出现「感谢你的反馈！」提示，新反馈即刻出现在列表中。
`creator_id` 与 `workspace_id` 由系统从登录态与当前工作区自动获取，无需手动填写。

- 提交失败：提示「反馈提交反馈失败，请稍后重试。」（或对应的具体校验提示）。
- 提交频率受限（每小时 10 条）：提示「too many feedback submissions, please try again later」（稍后重试）。

## 5. 点赞 / 取消点赞（需要登录）

在列表卡片或详情页点击「👍 支持」即可点赞；点赞后按钮变为「👍 已支持」，计数 +1。
再次点击取消点赞，计数恢复。

- 同一用户对同一反馈**最多只能点赞一次**（系统保证不会重复计数）。
- 刷新页面后，你的点赞状态会保留（「👍 已支持」）。
- 未登录时点赞按钮不可用（禁用态）。

## 6. 评论（需要登录）

在反馈详情页底部输入评论内容，点击「发送」（或按 `Ctrl/⌘ + Enter`）发表。评论会立即出现在列表中。
- 评论内容 ≤5000 字符。
- 未登录用户看不到评论输入区。
- 评论失败时提示「评论发送失败，请稍后重试。」。

## 7. 常见问题

| 问题 | 说明 |
|---|---|
| 看不到「反馈」导航 | 请先登录并进入任意工作区；反馈中心属于 workspace 级功能 |
| 想修改或删除已提交的反馈 | 本期不支持删除/编辑反馈；如需更正建议重新提交或联系维护者 |
| 想修改/删除自己的评论 | 本期不支持编辑/删除评论 |
| 反馈为什么需要登录 | 遵循 Multica 现有 workspace 强制登录机制；提交 / 点赞 / 评论为写操作，必须登录 |
